# Open media attribution

The portfolio keeps its original 3D screen geometry, video placement, animation and transition behavior. Only the requested project-video sources are substituted with openly licensed media. No custom video compositor, carousel, slide system or replacement billboard layout is used by `promo-social.js`.

The runtime deterministically maps each original project-video path to one media item. It does not rotate or slide content. If a chosen open-media source fails, it tries another open-media source; it never restores the original project video.
